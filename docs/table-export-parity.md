# 三表の画面とExcel出力の検証

通常画面と入出力は独立した表示条件と列構成を持ちます。総原価表の通常画面は前年・単一予算・差の3列、両予算では5列です。Excelは出力条件に従う3列で、両予算では一次・確定・差を出します。展開表の画面は独立選択した同じ前年を各予算列へ置きますが、Excelの前年行は各予算の基準前年とその差を保持します。Excelの予算見出しには基準前年を含めます。画面や出力を相手へ揃える変更はしません。

`npm run test:excel`の`tests/report-parity.mjs`は実際のReact部品を描画し、共有する予算・施策・期間・差額の金額、行順と結合を、生成・シリアライズ・再読込した.xlsxと照合します。`tests/report-contract.mjs`は、総原価表の対応列の選択、一次・確定の出力順、出力固有の見出しと展開表の基準前年行だけを明示的に対応付けます。期待値をExcel自身から作らず、元の画面セル・出力条件・基準前年の計算値を使います。ゼロの空欄・未設定・利益率・ポイント差、四半期・半期・年間も対象です。

全機能・前年実績・基準前年の異なる組み合わせ・施策なし・正負の丸め境界・科目属性未設定・分類絞り込みの8条件で、一次のみ・確定のみ・両予算・逆順選択と施策種別2通りを検証します。出力の保存済み計算結果に加え、計算元から数式を独立再計算した値も照合します。Excelの表示形式は画面の整形関数とは独立して解釈します。見出し・値・結合を意図的に壊す対照も検査します。元金額の編集・追加と大きい金額の1円精度は`tests/report-workbook.mjs`でも確認します。

`tests/ui/report-parity.spec.ts`は実際の入出力操作で生成したExcelの内容をメモリで受け取り、通常幅・狭幅で一次のみ・確定のみ・両予算の画面と照合します。通常画面の前年表示を変えても、既に出力したExcelの条件・値は変わらないことを確認します。OSのファイルへ保存しません。`npm run test:ui:excel -- report-parity.spec.ts`、build済みなら`npm exec -- playwright test --config playwright.excel.config.ts report-parity.spec.ts`で実行できます。

通常の`npm test`・`npm run verify`・画面テストにはExcel専用検証を含めません。施策一覧は初期の表示順を対象とし、一時的な並べ替え・大量行の省略描画・スクロールは既存の専用画面テストが補います。Excelとブラウザの画素・フォントの同一性、実Excelアプリによる再計算、読み上げソフトやOSファイル選択は保証範囲に含めません。
