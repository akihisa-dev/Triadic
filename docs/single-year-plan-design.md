# 単年度ファイルと予算種別の設計

製品仕様の正本は[製品方針と要件](../REQUIREMENTS.md)。保存する正本と更新範囲は[月別金額と保存構造](../DATA_MODEL.md)を参照する。

## 保存データと金額

一つのファイルで一つの基準年度を管理し、4月から翌3月までを扱う。表示上の種別は前年見込・前年実績・一次予算・確定予算とする。前年は見込・実績別に科目・業種・部署・月ごとの金額で、施策には含めない。予算の保存種別は一次予算と確定予算の固定2件とする。

施策は名称・備考・展開・業種・部署・期間と科目行を共有し、金額領域だけを一次予算・確定予算のタブにする。基準前年を一次・確定それぞれについて前年見込・前年実績から選ぶ。両予算の入力額は前年差とし、総原価表と展開表の合計は前年値＋施策の増減合計とする。

一次予算は各行に12か月分を保存する。確定予算は手修正した月だけ保存し、未修正月は一次予算に追従する。0の手修正も固定する。セル内は数値だけとし、引き継ぎの注記や個別ボタンは置かない。全月を編集可能とする。

同じ科目の複数行を独立して保持する。共通科目行は金額の有無で科目変更・削除を制限しない。科目変更は両予算の月額・手修正・明示0・引き継ぎを保持し、行削除は対象行の両予算の金額も削除する。自動保存の実行中は確定を待つ。

## 表の選択と比較

総原価表・展開表は、行を前年見込・前年実績、列を前年・一次予算・確定予算とする3列のチェック欄で選びます。前年は見込・実績の一方、予算は各列で独立した基準前年を選び、一次・確定の少なくとも一方を表示します。一つの列の変更で他の列の選択・金額を変えません。

| 画面 | 初期状態 | 選択と表示 |
|---|---|---|
| 施策一覧 | 確定予算 | 1つの選択欄で予算を切り替え、売上・費用・利益を表示 |
| 総原価表 | 前年見込・前年見込基準の一次予算 | 1予算時は前年・予算・予算−前年の3列。両予算時は前年・一次・確定・確定−前年・確定−一次の5列。前年の表示と予算の基準前年は独立 |
| 展開表 | 前年見込・前年見込基準の一次予算 | 前年は既存の上部行だけに表示し、前年列は設けない。選択した予算ごとの売上・利益と、両予算時だけ確定−一次の売上・利益を表示 |

総原価表の差額は表示中で最も後の種別から各先行表示対象を引きます。前年見出しは前年見込／前年実績、予算見出しは一次予算／確定予算の一行とし、差額見出しに引き算の両対象を示します。予算は各予算の基準前年＋施策増減、前年差は独立選択した表示前年との差です。利益率の差はポイントで示します。

入出力は前年列のない予算2列の比較条件を表別に選び、通常画面とは独立します。Excel出力は入出力で選択した各予算の基準前年と出力用の列構成を使います。通常画面と同じ列構成へ揃えません。細則は[製品要件](../REQUIREMENTS.md#種別分類の表示選択)と[README](../README.md#表の表示と種別の選択)を参照します。

3画面の選択はファイルへ画面別に保存し、画面の往復・再読込・履歴の復元で保持する。保存中は選択を止め、保存に失敗したら保存済みの選択と表を維持して理由を通知する。過去閲覧中は選択を一時的に変更でき、ファイルには保存しない。

施策一覧・展開表は業種・部署の全件を対象とし、分類の選択欄を設けない。総原価表は部署名・業種名の順に並べたドロップダウンで、各分類の個別候補または全件合計を選ぶ。部署に応じた業種候補の制限と単一候補の自動選択は製品方針と要件に従う。分類選択は画面内だけに保持し、ファイルには保存しない。施策一覧・展開表・総原価表の内訳は、金額列を含む対象列の見出しから並べ替え・絞り込みを行う。施策一覧と内訳は表示中の行の合計、展開表は基準前年全体と表示中の施策の合計を示す。総原価表本体には、科目と集計の位置関係を保つためこの見出し操作を設けない。条件と表示順はウィンドウ内のメモリだけに保持し、施策一覧と展開表は詳細から戻ると復元する。ファイルを閉じると破棄し、ファイル・登録順・保存済み金額・Excel出力の範囲は変更しない。詳細は[製品方針と要件](../REQUIREMENTS.md)と[実装済み機能](../README.md#表の表示と種別の選択)を参照する。

## 保存形式と削除範囲

保存構造と対応形式は[月別金額と保存構造](../DATA_MODEL.md)と[README](../README.md)を正とする。旧ファイルは理由を表示して読み込みを拒否し、移行・読み替え・上書きを行わない。新規ファイルから利用する。

修正予算・見通し・実績は保存種別、手修正、引き継ぎ、入力・表示から削除する。修正予算の開始状態と開始・取消操作、4〜9月の編集禁止、種別表示の旧初期設定も持たない。

保存失敗・キャンセル・外部変更では元のデータを保持する。集計結果と引き継ぎ値は別の保存値として複製せず、金額は円単位の整数を正本とする。

## 検証条件

- 一次予算の変更が未修正の確定予算へ伝わり、手修正と手修正0は固定され、解除後に追従する。
- 総原価表の1予算3列・両予算5列、表示前年の独立選択と各予算の基準前年、差額の両対象と符号を確認する。展開表の前年は上部行だけ、両予算時だけ確定−一次を表示する。入出力の独立した条件とExcel用の列構成を維持する。
- 総原価表の部署・業種の個別候補／全件合計、部署の所属による業種候補の制限と単一業種の自動選択、施策一覧・展開表・総原価表の内訳の金額列を含む並べ替え・絞り込みと、表示対象に応じた合計を確認する。総原価表本体の科目・集計構造を維持し、分類選択・並べ替え・絞り込みで保存済みの金額・登録順・Excel出力の範囲を変更しない。
- 見出し条件と表示順は施策一覧・展開表の詳細からの復帰で復元し、ファイルを閉じると破棄する。条件をファイルへ保存しない。
- 選択の画面別保存、未選択への復帰、重複拒否、再読込、履歴の復元、保存失敗時の表示保持を確認する。
- 前年・両予算で元データと各表の金額が一致し、共通科目行の保護と全月の編集を確認する。
- 旧形式の拒否と元ファイルの非変更、精度・分類・参照の検証、保存失敗・競合時の保護を確認する。
