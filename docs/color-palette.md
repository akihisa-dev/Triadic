# 画面のカラーパレット

正本は `Triadic-extension/src/extension/styles/palette.css`。画面部品は用途名のCSS変数を参照し、色番号を直接持たない。ライトの背景・面・罫線は黄みを抑えた象牙色とグレー、文字は墨色を使う。ダークは墨色の背景と象牙色の文字を使い、操作対象だけをライトは青、ダークは金で示す。

| 用途 | 変数 | ライト | ダーク |
|---|---|---|---|
| 画面背景 | `--canvas` | `#F7F7F3` | `#292929` |
| 入力欄・表・ダイアログの面 | `--surface` | `#FBFBF8` | `#343434` |
| 見出し・淡い選択背景 | `--soft` | `#EEEEE9` | `#40403D` |
| 本文・数値 | `--ink` | `#343434` | `#F4F0E6` |
| 補助文字 | `--muted` | `#666660` | `#BDB9AF` |
| 画面・パネルの区切り線 | `--line` | `#C6C6BD` | `#62625B` |
| 表の通常罫線 | `--table-line` | `#B9B9B0` | `#707068` |
| 月・集計・固定部分の境界 | `--table-divider` | `#9B9B92` | `#929287` |
| 入力欄・選択範囲の枠 | `--control-line` | `#8B8B84` | `#8F8C82` |
| トグル・スクロールつまみの面 | `--control-track` | `#D5D5CE` | `#55544F` |
| 操作対象のアクセント | `--accent` | `#0033FF` | `#D6B86C` |

## 用途と派生色

- `--line` は画面・パネルの区切り、`--table-line` は行・セルの通常罫線、`--table-divider` は月・期間・主要集計・固定部分・列見出しの境界。基本1pxのまま明暗差で強弱を付ける。背景色から混ぜて作らず、期間列や選択背景でも線が残る独立した色を使う。
- `--period-quarter`・`--period-half`・`--period-annual` は四半期・半期・年間を順に濃くする不透明な背景。固定列や見出しの背後を透かさない。
- `--selected-month` と `--period-annual` はライト `#D5D5CE`、ダーク `#55544F`。`--period-half` は `--soft` と `--period-annual` の中間。線色と独立させ、線の調整で承認済みの背景色を変えない。選択月の文字は `--ink` を組み合わせる。
- `--on-ink` は本文色で塗ったボタンの文字、`--ink-hover` はそのホバー背景、`--inverse-muted` は反転面の補助文字。
- `--focus` はボタン・図・表領域のキーボードフォーカス。通常の文字色を使う。入力中の枠・文字カーソルは `--accent`。
- `--accent-ink` は集計の所属先。ライトの既存の控えめな青を保ち、ダークでは金を使う。`--accent-subtle`・`--accent-soft`・`--accent-selected`・`--accent-drop` は所属・選択・ドロップ先の淡い面。ダークは金と面を混ぜて作る。
- 影は `--shadow-rgb`、ダイアログ背後は `--backdrop`。形・配置・動きは各部品の既存定義に従う。

本文・補助文字・操作対象は実際の背景との明暗差を確認する。アクセント色を表の通常数値や通常ボタンの面へ広げない。青・金の違いだけに操作の意味を依存させず、既存のラベル・選択状態・下線を保持する。

通常入力枠と選択枠は通常罫線より明確にし、編集中のアクセント枠を優先する。集計マスタのL字と「画面とデータ」の接続線は関係を読むための境界色を使う。狭幅で結合セルの表示幅を切り取る合計ラベルは、見えている固定列の右端に1pxの線を描く。月と期間の接合部は片側だけが線を持ち、二重線を作らない。

このパレットは画面専用。計画ファイル・履歴・Excel出力・配布ロゴ画像の色には適用しない。配色の変更時は両テーマの入口・表・マスタ・ダイアログと狭幅をブラウザで確認し、`palette.spec.ts`・`colors.spec.ts`・`theme.spec.ts` の操作と表示の検証を行う。
